
# Student Stress Analysis System

## Project Overview
This project analyzes student stress levels using lifestyle, academic, social, and image-based factors.

## Tools Used
- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Scikit-learn
- Pillow

## Main Modules
- Overview
- Analytics Dashboard
- Stress Prediction
- Face Biometric Stress
- Dataset

## How to Run
```bash
pip install -r requirements.txt
python data_cleaning.py
streamlit run app.py
```

## Resume Description
Developed a Student Stress Analysis System using Python, Pandas, Plotly, Streamlit, Scikit-learn, and Pillow. Analyzed lifestyle and academic factors such as sleep, study hours, screen time, academic pressure, and social support to identify stress patterns. Built an interactive dashboard with machine learning based stress classification and image-based stress percentage generation.
